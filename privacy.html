M3-Backup 개인정보처리방침

적용 범위: M3-Backup 개인용 Google Drive 백업 기능 및 이 소개 웹사이트.

1. 접근하는 Google 데이터

소유자가 동의하면 Google Drive의 drive.file 범위에서 앱이 생성하거나 접근을 허용받은 파일을 처리합니다. 백업 대상 영상 파일 내용, 이름, 크기, 식별번호, SHA-256 파일 지문과 작업 상태가 포함될 수 있습니다. 다른 Google Drive 전체 파일 접근 권한은 요청하지 않습니다.

2. 처리 목적

영상의 비공개 백업, 중복 방지, 서버 복원 검증 및 전송 오류의 안전한 재시도에만 사용합니다. Google 사용자 데이터를 광고 개인화 또는 판매 목적으로 제공하지 않습니다.

3. 보관 위치

영상 백업은 사용자 본인의 Google Drive에 저장됩니다. Google 인증 정보는 사용자가 관리하는 컴퓨터의 접근 제한된 로컬 설정에 저장하며 공개 사이트·GitHub 코드 저장소에는 게시하지 않습니다.

4. 제3자 서비스와 웹사이트

영상 파일 저장과 다운로드에는 Google Drive를 이용합니다. 안내 사이트는 GitHub Pages에서 제공되며 GitHub가 방문자의 접속정보를 자사 정책에 따라 기록할 수 있습니다. 본 안내 사이트에는 별도 회원가입, 광고 추적기, 사용자 정보 입력 양식을 설치하지 않았습니다.

5. 보관·철회·삭제

백업 파일은 사용자가 Google Drive에서 삭제하기 전까지 남을 수 있습니다. Google 계정의 연결된 앱 설정에서 앱 접근을 취소할 수 있지만, 접근 권한을 끊어도 기존에 저장된 백업 파일은 자동 삭제되지 않습니다. 로컬 기록은 복구와 중복방지를 위해 사용자의 컴퓨터에서 관리합니다.

6. 문의

GitHub 공개 문의 게시판을 이용할 수 있습니다. 개인정보와 비밀번호는 공개 게시하지 마세요.

본 사이트는 M3-Backup 앱 소개용이며 영상 원본·백업 파일·인증키를 공개하지 않습니다.
